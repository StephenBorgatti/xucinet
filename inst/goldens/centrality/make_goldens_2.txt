// All under Network | Centrality unless stated. Defaults UNCHANGED, please:
// the defaults are what we are recording.
//
//  #  Menu item                     Dataset      Save output as
// --  ----------------------------  -----------  ---------------------
//  1  Reach Centrality              campnet      g9m_reach_campnet
//  1  Reach Centrality              g9_disc      g9m_reach_disc
//  2  Beta Reach Centrality         campnet      g9m_breach_campnet
//  2  Beta Reach Centrality         g9_disc      g9m_breach_disc
//  3  Hubs && Authorities           campnet      g9m_hubs_campnet
//  3  Hubs && Authorities           baker_journals  g9m_hubs_baker
//  4  Induced Centrality            campnet      g9m_induced_campnet
//  4  Induced Centrality            g9_iso       g9m_induced_iso
//  5  Network | 2-Mode networks |   g9_small2    g9m_2mode_small
//     2-Mode Centrality                          (and its COLUMN output as
//                                                 g9m_2mode_small_col)
//
// WHY EACH
//
//  1-4  These four have no command keyword and no fixtures at all, so there is
//       nothing to write the routines against. Two datasets each: campnet for
//       the ordinary directed case, and g9_disc or g9_iso for the case that
//       exposes what the routine does when something is unreachable or
//       isolated, which is where conventions differ.
//
//  3    Hubs and Authorities on baker_journals as well, because it is valued
//       and directed, and HITS on valued data is exactly where an
//       implementation can silently dichotomize without saying so.
//
//  5    2-mode centrality is now SOLVED and does not block anything; this run
//       is confirmation on a second shape rather than discovery. All five
//       measures reproduce g9m_2mode_davis and davis-colcent to 1e-8, and the
//       one that needed real work was betweenness.
//
//       Steve pointed at Borgatti and Everett (1997), Social Networks 19,
//       243-269. Page 256 gives the bipartite maximum in two branches. The
//       n_o <= n_i branch is right - it is algebraically identical to what
//       UCINET computes, and the test checks that for every shape up to 10.
//       The n_o > n_i branch, 2(n_o - 1)(n_i - 1), is NOT: for davis rows it
//       gives 442 where UCINET gives 445, and 445 is what reproduces the
//       fixture. UCINET's getmax() in uc_twomodecentrality.pas implements a
//       single general formula instead, which is presumably the result the
//       paper says "will be the subject of a separate paper".
//
//       davis only exercises s = 1, t = 3 in that formula. g9_small2 is 5 x 3,
//       so its rows give s = 1, t = 1 and its columns s = 0, t = 2 - a
//       different corner of the same function, and small enough to check by
//       hand from the log. That is worth having before the book quotes a
//       normalization.
//
